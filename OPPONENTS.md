## To be left out

Either of these works:

- Open an issue on this repo asking to be removed: https://github.com/armanckeser/github-stars-organizer/issues/new?title=Remove%20me%20from%20OPPONENTS.md
- Add a file called `no-play` (any content) to a public repo called `stard` on your account. Within an hour, the account is no longer an opponent, and the Worker reads its stars only for runs the account plays itself.
