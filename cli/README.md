# github-stars-organizer

Search, tag, rate and sort your GitHub stars into Lists that sync back to GitHub.

```bash
npx github-stars-organizer
```

Uses your `gh` login (or `GITHUB_TOKEN`) and opens http://127.0.0.1:5185. Ctrl-C to quit.

- Backs up your stars and Lists to `~/.github-stars-organizer/backups/` before every launch.
- Talks only to `api.github.com`. No telemetry; your data stays on your machine.

Source and demo: https://github.com/armanckeser/github-stars-organizer
